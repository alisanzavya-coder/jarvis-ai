JARVIS 3D — راهنمای خیلی ساده (ویندوز)

این نسخه یک رابط سه‌بعدی شیشه‌ای، چت فارسی، ورودی صوتی مرورگر، ساعت ایران، جستجوی خبرهای Google News و اتصال به API هوش مصنوعی دارد.

شروع:
1) ZIP را با راست‌کلیک > Extract All از حالت فشرده خارج کن.
2) Python 3 را از python.org نصب کن. هنگام نصب تیک Add Python to PATH را بزن.
3) روی INSTALL.bat دوبار کلیک کن و صبر کن تا تمام شود.
4) روی RUN_JARVIS.bat دوبار کلیک کن. پنجره مشکی را نبند؛ برنامه در Chrome باز می‌شود.
5) در برنامه وارد «تنظیمات اتصال» شو و کلید API، آدرس API و مدل ارائه‌دهنده‌ات را وارد کن. سپس «ذخیره... و آزمایش اتصال» را بزن.

تنظیمات نمونه برای API سازگار با OpenAI:
Base URL: https://api.openai.com/v1
Model: نام مدلی که در حساب ارائه‌دهنده‌ات در دسترس است
API key: کلید API خودت

مهم:
- این برنامه خودش کلید API رایگان فراهم نمی‌کند. باید از ارائه‌دهنده هوش مصنوعی کلید معتبر داشته باشی؛ هزینه و دسترسی به کشور/حساب/ارائه‌دهنده بستگی دارد.
- کلید واردشده در این نسخه فقط در session مرورگر نگهداری می‌شود و به سرور محلی خودت فرستاده می‌شود. کلید را در رایانه مشترک وارد نکن.
- اخبار از Google News RSS دریافت می‌شوند؛ دسترسی به اینترنت لازم است. خلاصه‌سازی خبرها با مدل هوش مصنوعی انجام می‌شود و ممکن است از عنوان‌ها اطلاعات محدودتری داشته باشد.
- جستجوی گوگل در یک زبانه جدید باز می‌شود.
- این نسخه هیچ فرمان خطرناک ویندوزی را اجرا نمی‌کند.
- اگر خطا دیدی، متن خطا را بفرست.

توقف:
پنجره سیاه RUN_JARVIS را انتخاب کن و Ctrl+C بزن.
